This is the Sims 4 Creator Tools's custom asset folder. You can drag and drop custom assets in this folder for the addon to load. No need to restart Blender.
You also have the option to set a custom folder path in the addon's prefrences. 

ONLY accepts .blend files. 
DO NOT drop .package files in here, it will NOT read them.

CAS - Create A Sim items. 
Will import any meshes with the "S4Studio_Mesh_" prefix (not case sensitive).

Body - Custom bodies meshes like EVE, Noir & Dark, etc. 
Will import any meshes with the "S4Studio_Mesh_" prefix (not case sensitive).

Rig - Custom rigs like Melodine, Vyxated, etc. 
Will import any collections with armatures and it's shapes (if any). Will make those shapes visible, sorry.

Anim - Custom animations from pose packs. 
Will import actions from rigs from the blend file. Will overwrite the current pose/animation your have applied to your sim at the time.
